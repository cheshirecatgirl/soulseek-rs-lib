# soulseek-rs-lib

The Soulseek protocol library from
[michel/soulseek-rs](https://github.com/michel/soulseek-rs) v19.1.0, on its
own, plus one commit of changes.

```toml
soulseek-rs-lib = { git = "https://github.com/cheshirecatgirl/soulseek-rs-lib", branch = "lib" }
```

Import it as `soulseek_rs`. `master` mirrors upstream. MIT, like upstream.
